حلقه اعتبارسنجی هدف (ناحیه 0x180023300):
  1) target_pos = read_vec3(target + 0x434)          ← موقعیت هدف
  2) W2S: screen = transform(target_pos, view_matrix)
  3) فیلتر FOV صفحه‌ای: if |screen.x| > TH or |screen.y| > TH → رد
     (TH = float ثابت @ 0x1800b0be8/0x1800b0b40 ناحیه — قابل تغییر از منو)
  4) مقایسه با هدف فعلی: دلتای صفحه جدید vs قدیم باید کوچک‌تر از TH باشد
  5) ذخیره هدف فعلی: screen → [0x1800d5558ish]، target_ptr → global
  6) rate-limit تعویض هدف: فقط اگر (now - last) >= 0xFA (250 واحد) اجازه تعویض
  7) hitGroup: call 0x1800356b0(pos, hit, 2) → انتخاب Body/Chest
     (رشته "Body/Chest" @ 0x1800b00d0؛ مقدار ریموت قابل ست)

«ok via legacy TypeInfo holder»، «ok via generic TypeInfo») پس حتی
بدون سرور هم می‌تواند افست بیلد جاری را بیرون بکشد.
